## Part 3 — Three Target Tasks for FL-02 through FL-04

These tasks will be used across the next three weeks of exercises.

### 🎯 Target Task 1: API Debugging & Error Resolution

**Task:** Debug backend API errors in Express.js / Node.js services built during my FlyrankAI internship.

**Classification:** Collaborate with AI

**"Done Well" Definition:**
- The root cause is correctly identified (not just patched)
- The AI-suggested fix is understood, not blindly applied
- The solution is accompanied by a comment explaining WHY the error occurred
- The fix is tested with at least one edge case
- Completion time is under 30 minutes for a typical bug (vs. ~2 hours solo)

**Measurable Success Metric:** ≥80% of bugs resolved within one debugging session, with documented understanding of the fix.

---

### 🎯 Target Task 2: Technical Research Summaries

**Task:** Research and synthesize new technical concepts (e.g., vector databases, RAG pipelines, auth patterns) to inform FlyrankAI project decisions.

**Classification:** Collaborate with AI

**"Done Well" Definition:**
- Research produces a clear 1-page summary with pros/cons and use-case fit
- At least one external source is verified beyond AI output
- The summary is actionable: includes a clear recommendation for the project
- Can explain the concept in my own words without referencing the AI output
- Written in under 45 minutes

**Measurable Success Metric:** Summary reviewed and approved by supervisor/team within one revision cycle.

---

### 🎯 Target Task 3: Writing Professional PR Descriptions & Documentation

**Task:** Draft pull request descriptions, README updates, and inline code documentation for internship submissions.

**Classification:** Delegate to AI with Review

**"Done Well" Definition:**
- PR description accurately describes what changed and why
- README is clear enough that a new team member can onboard using it alone
- Inline comments explain non-obvious logic (not just what the code does)
- No factual errors about the codebase — everything I say in docs must be true
- Zero grammatical or spelling issues

**Measurable Success Metric:** PRs merged on first or second review cycle with no documentation-related change requests.
